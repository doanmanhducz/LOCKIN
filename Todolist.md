# LOCKIN – Feature Todo List

## 1. Portfolio & Blog
- Display personal info from CV (Name, Objective, Education, Skills, Experience, Projects, Publications, GitHub/LinkedIn)
- Blog CRUD:
  - Create/Edit/Delete/View posts
  - Search by title/content
  - Filter by tag
  - Rich text editor (Draft.js/Quill)
- Blog cards with date, title, tags, short content preview

## 2. Todo List
- CRUD todos
- Calendar view: daily/weekly/monthly/yearly
- Status: Todo/In progress/Done
- Stats: total tasks, completed, overdue
- Sync with DB
- Drag/drop optional for tasks

## 3. Meal & Gym Tracking
- Meal tracker:
  - Name, calories, date/time
  - List meals by day/week
- Gym tracker:
  - Exercise type, sets/reps, calories burned
  - Weekly/monthly summary charts
- Calculate calories in/out
- Store logs in DB

## 4. Pomodoro Timer
- Timer: 25 min work / 5 min short break / 15-30 min long break
- Start/Pause/Reset
- Session count
- Optional notifications when session ends
- Show progress visually

## 5. General
- Each feature must have:
  - Backend API
  - Frontend UI connected to API
  - Mock data for local testing
- Local dev first, deployment later
